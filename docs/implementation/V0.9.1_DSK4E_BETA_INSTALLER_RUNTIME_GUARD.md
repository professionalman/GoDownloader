### 1. Executive Summary

DSK-4E establishes the packaged build pipeline, cross-process runtime ownership guard, and CWD-independent data layout for the GoDownloader V0.9.1 Windows Desktop Beta.

#### Core Deliverables
1. **Cross-Process Durable-Core Runtime Guard (`internal/runtimeguard`)**:
   - Kernel-enforced single ownership of the durable SQLite data store.
   - Works uniformly across desktop, server, and headless CLI invocations.
   - Win32 `CreateFile` exclusive file lock (`shareMode = 0`) on `<canonical_db>.runtime.lock`.
   - POSIX fallback via `syscall.Flock` (`LOCK_EX | LOCK_NB`).
   - Maps collision errors (`ERROR_SHARING_VIOLATION`, `ERROR_LOCK_VIOLATION`) to sentinel `ErrRuntimeAlreadyOwned`.
   - Automatically releases on process exit or crash with zero stale-lock poisoning.
2. **Desktop Data-Root & CWD-Independence Closure**:
   - `internal/config.New()` is pure and performs zero filesystem mutations or eager directory creations.
   - Directory creation moved to explicit `EnsureDirectories()` called on-demand after runtime guard acquisition.
   - Desktop runtime strictly anchors database and application directories under `%APPDATA%\GoDownloader`.
   - Launching desktop or server from any arbitrary foreign working directory creates zero files or directories in that CWD.
3. **Truthful V0.9.1 Packaged Build Identity**:
   - Canonical version advanced to `0.9.1` across `build/config.yml`, `build/windows/info.json` (`0.9.1.0`), and `build/windows/wails.exe.manifest`.

   - PE version resource verified on binary (`ProductVersion = 0.9.1`, `FileVersion = 0.9.1.0`, `FileDescription = GoDownloader Windows Desktop Beta`).
   - Source code default remains `(devel)` to maintain truthful un-injected builds.
4. **Internal Windows x64 NSIS Beta Installer Fixture**:
   - `build/windows/installer.nsi` and `wails3 task windows:package`.
   - User-level execution level (`RequestExecutionLevel user`), installing into `$LOCALAPPDATA\Programs\GoDownloader`.
   - Preflight checks in `.onInit`: 64-bit Windows requirement (`RunningX64`), Microsoft Edge WebView2 Evergreen runtime check, and running core lock check.
   - Payload: Delivers `GoDownloader.exe`, writes `Uninstall.exe`, creates Start Menu shortcut, and registers `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\GoDownloader`.
   - Running-core protection: Pre-checks runtime lock in `un.onInit` and aborts if core is active.
   - Clean uninstall removes binaries, shortcuts, uninstall registry entry, and any matching autostart Run key.
   - Strict data preservation: `%APPDATA%\GoDownloader` database, configuration, and download directories are strictly preserved.
5. **Acceptance & Regression Verification**:

### 2. Architecture & Design

```
+-----------------------------------------------------------------------------------+
|                              Operating System / Host                              |
+-----------------------------------------------------------------------------------+
                                          |
                   +----------------------+----------------------+
                   |                                             |
        [ Desktop Process ]                             [ Server Process ]
                   |                                             |
        +----------v----------+                                  |
        | Wails SingleInstance|                                  |
        | (Activate / Forward)|                                  |
        +----------+----------+                                  |
                   | (First desktop instance)                    |
                   v                                             v
        +----------------------------------------------------------------+
        |                 internal/runtimeguard.Acquire()                |
        |       Path: %APPDATA%\GoDownloader\downloader.db.runtime.lock  |
        |     Win32 CreateFile(shareMode=0) / POSIX flock(LOCK_EX|NB)    |
        +--------------------------------+-------------------------------+
                                         |
                       +-----------------+-----------------+
                       |                                   |
                  [ Success ]                         [ Collision ]
                       |                                   |
          +------------v------------+         +------------v------------+
          | Owns SQLite Data Store  |         | ErrRuntimeAlreadyOwned  |
          | cfg.EnsureDirectories() |         | Desktop: Native Win32   |
          | app.Start()             |         |   MessageBoxW dialog    |
          | Database & Background   |         | Server: Fatal log error |
          | Workers Online          |         | Clean exit code 1       |
          +-------------------------+         | ZERO mutations in CWD   |
                                              +-------------------------+
```

#### 2.1 Cross-Process Runtime Guard (`internal/runtimeguard`)
- **Location:** `internal/runtimeguard/guard.go`, `guard_windows.go`, `guard_unix.go`, `guard_test.go`.
- **Lock Target Derivation:** Canonical absolute path normalization via `filepath.Abs(filepath.Clean(dbPath))` appending `.runtime.lock`.
- **Windows Implementation:**
  - Invokes `golang.org/x/sys/windows.CreateFile`:
    - `access = GENERIC_READ | GENERIC_WRITE`
    - `shareMode = 0` (exclusive, denying other processes read, write, or delete access)
    - `creationDisposition = OPEN_ALWAYS`
    - `flagsAndAttributes = FILE_ATTRIBUTE_NORMAL`
  - When another process holds the handle, Windows returns `ERROR_SHARING_VIOLATION` (32) or `ERROR_LOCK_VIOLATION` (33), mapped directly to `runtimeguard.ErrRuntimeAlreadyOwned`.
  - Closing the `Guard` invokes `windows.CloseHandle`.
- **POSIX Implementation:**
  - Opens `<canonical_db>.runtime.lock` with `os.OpenFile(O_CREATE|O_RDWR)`.
  - Invokes `syscall.Flock(fd, syscall.LOCK_EX | syscall.LOCK_NB)`.
  - Maps `syscall.EWOULDBLOCK` and `syscall.EAGAIN` to `ErrRuntimeAlreadyOwned`.
- **Lifecycle Integration (`internal/app`):**
  - In `app.New()`, Step 0 acquires the runtime guard BEFORE SQLite database initialization or tool/engine probing.
  - Registered in `cleanupStack` so initialization failure rolls back the guard cleanly.
  - In `app.Shutdown()`, Step 5 releases the guard strictly AFTER SQLite database connection closure (`db.Close()`).
- **Crash Safety:**
  - Kernel locks are process-bound. If a process crashes or is killed (`SIGKILL` / `taskkill`), the OS kernel immediately releases the file handle. Subsequent processes can acquire the lock immediately without stale lock file issues.

#### 2.2 Desktop Shell vs Core Runtime Ownership
- **Wails Desktop SingleInstance:**
  - Configured in `cmd/desktop/main.go` with `UniqueID: "com.godownloader.desktop.app"`.
  - Serves user-facing desktop UX: secondary launches forward arguments to the existing window and restore focus (`ExitCode: 0`).
- **Core Runtime Guard:**
  - Serves durable backend ownership: prevents two running processes (e.g. desktop + server, or multiple independent hosts) from concurrently opening and corrupting the same SQLite database.
  - Contention cleanly exits with code `1` and shows a native Win32 `MessageBoxW` dialog when invoked as desktop.

#### 2.3 CWD Independence & Pure Configuration
- **Pure `config.New()`:**
  - Removed eager `os.MkdirAll` directory creations from `config.New()`.
  - Added `cfg.EnsureDirectories() error` to `internal/config`.
  - In `cmd/server/main.go` and `cmd/desktop/main.go`, `cfg.EnsureDirectories()` is only called AFTER runtime ownership is secured.
  - If runtime ownership collision occurs, the process exits without creating `./data` or `./downloads` in the execution CWD.
- **Desktop Data Root:**
  - `cmd/desktop/data_root.go` resolves `%APPDATA%\GoDownloader` on Windows.
  - Database is anchored to `%APPDATA%\GoDownloader\downloader.db`.
  - Tested from arbitrary foreign directories: 0 files leaked.

#### 2.4 NSIS Beta Installer Fixture (`build/windows/installer.nsi`)
- **Execution Level:** `RequestExecutionLevel user` (installs to `%LOCALAPPDATA%\Programs\GoDownloader`).
- **Preflight Validations (`.onInit`):**
  - 64-bit Windows requirement (`${IfNot} ${RunningX64}`).
  - Microsoft Edge WebView2 Evergreen runtime check across HKCU/HKLM Registry keys.
  - Core lock check: checks `%APPDATA%\GoDownloader\downloader.db.runtime.lock` to ensure GoDownloader is not active during installation.
  - All `.onInit` message boxes use `/SD IDOK` for non-blocking silent execution (`/S`).
- **Uninstaller Safety (`un.onInit`):**
  - Checks `%APPDATA%\GoDownloader\downloader.db.runtime.lock`. If locked, displays warning and aborts with exit code 2.
  - Deletes payload binaries (`GoDownloader.exe`, `Uninstall.exe`) and installation directory.
  - Deletes Start Menu shortcuts.
  - Cleans `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` `godownloader` value only if it matches the uninstalled binary path.
  - Deletes `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\GoDownloader`.
  - **Preserves User Data:** `%APPDATA%\GoDownloader` data store and user download directories are strictly preserved.
