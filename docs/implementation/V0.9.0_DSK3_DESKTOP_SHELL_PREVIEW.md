## 1. Executive Summary & Verdict

Milestone **DSK-3** introduces the first production Windows desktop host (`cmd/desktop`) for GoDownloader, realizing the accepted Wails v3 architecture evaluated in `SPK-SYN3-01`.

### Key Outcomes:
1. **Core Reuse Without Duplication:**
   `cmd/desktop` initializes the exact application runtime extracted in `DSK-1` (`internal/app.New`, `Start`, and `Shutdown`). The desktop host wires no duplicate repositories, engines, or schedulers. Exactly one `App` instance exists per primary process.
2. **Embedded Production React Application:**
   The production React application is built via Vite multi-page configuration into `web/dist`, producing both `dist/index.html` (for server web mode) and `dist/desktop.html` (for desktop mode). Assets are embedded directly into the Go binary via standard library `//go:embed` in `web/embed_production.go` (`//go:build production`) and served in-process by Wails `application.AssetFileServerFS`. A dev build fallback in `web/embed_dev.go` (`//go:build !production`) provides an empty `embed.FS` so that `go test ./...` and developer builds succeed on clean checkouts without requiring pre-built frontend artifacts.
3. **Framework-Neutral Transport Realization:**
   `web/src/desktop.tsx` synchronously installs `desktopBackendClient` (`web/src/transport/desktop.ts`) into the framework-neutral client slot before React mounts (`mountApp()`). Shared React components execute zero runtime host-checking or browser-sniffing branches.
4. **Native Typed IPC:**
   All 7 domain namespaces (`jobs`, `queue`, `settings`, `categories`, `tracker`, `mediaAuth`, `sync`) are exposed by `DesktopService` (`cmd/desktop/service.go`) and invoked through auto-generated Wails v3 bindings (`web/src/bindings/downloader/cmd/desktop/desktopservice.ts`).
5. **Native StateSync & Live Event Streaming:**
   The `App.EventBus()` fan-out channel is bridged into Wails native events (`godownloader.event`). The desktop client subscribes via `@wailsio/runtime` `Events.On`, maintaining cursor progression, snapshot hydration, gap detection (`seq > cursor + 1` triggers `sync.required`), and rehydration without HTTP polling.
6. **Zero Listening Localhost Sockets:**
   Normal desktop operation starts no HTTP server, Gorilla mux router, or SSE listener. Process port audits confirm **zero listening TCP ports**.
7. **Native Single-Instance Enforcement:**
   Mutual exclusion is enforced at process start by Wails v3 `SingleInstanceOptions`. Secondary instances exit cleanly with exit code 0 inside `application.New()`, forward arguments and working directory via IPC to the primary instance, and construct zero duplicate application cores.
8. **Clean Shutdown:**
   Desktop window close or explicit `Quit` executes `App.Shutdown(ctx)`, cleanly terminating supervised processes, flushing SQLite WAL, and releasing resources with exit code 0.

## 3. Implementation Details

### A. Windows Data Root Resolution (`cmd/desktop/data_root.go`)
- Desktop mode resolves per-user application storage deterministically to `%APPDATA%\GoDownloader`.
- Automatically ensures directories: `%APPDATA%\GoDownloader\data`, `%APPDATA%\GoDownloader\data\torrents`, and `%APPDATA%\GoDownloader\downloads`.
- Independent of invocation CWD (proven when launched from repository root and `$env:TEMP`).

### B. In-Process Service (`cmd/desktop/service.go`)
- In-process `DesktopService` struct registered with Wails v3 via `application.NewService(service)`.
- Implements all 7 domain namespaces required by `BackendClient`:
  - `jobs`: `GetJobs`, `GetJob`, `CreateJob`, `CreateBatchJobs`, `PauseJob`, `ResumeJob`, `RetryJob`, `CancelJob`, `DeleteJob`, `BulkAction`, `SetJobPriority`, `SelectFormat`, `UploadTorrent`, `GetTorrentFiles`, `StartTorrent`, `StopSeeding`, `GetCapabilities`, `ResolveCapabilities`, `GetJobCapabilities`, `UpdateJobNetwork`, `AddTorrentTrackers`, `UpdateSeedingPolicy`, `OpenFolder`.
  - `queue`: `GetQueueSnapshot`, `ReorderQueue`.
  - `settings`: `GetSettings`, `UpdateSettings`.
  - `categories`: `GetCategories`, `CreateCategory`, `UpdateCategory`, `DeleteCategory`.
  - `tracker`: `GetTrackerSources`, `CreateTrackerSource`, `UpdateTrackerSource`, `DeleteTrackerSource`, `RefreshTrackerSource`, `RefreshAllTrackerSources`.
  - `mediaAuth`: `GetMediaAuthSettings`, `UpdateMediaAuthSettings`, `ImportMediaCookies`, `DeleteMediaCookies`.
  - `sync`: `GetSyncSnapshot`.
  - `diagnostics`: `GetBackendInstanceID`, `GetDataRootInfo`, `GetSingleInstanceStatus`, `ShowNativeDialog`, `Quit`.
- Error mapping formats Go errors into `[ERROR_CODE] message`, which `web/src/transport/desktop.ts` unwraps into `ApiResponseError(code, message)`.

### C. Frontend Desktop Bootstrap (`web/desktop.html`, `web/src/desktop.tsx`)
- Multi-page Vite configuration (`web/vite.config.ts`) builds both `index.html` and `desktop.html`.
- `web/src/desktop.tsx`:
  ```typescript
  import { setBackendClient } from './api';
  import { mountApp } from './bootstrap';
  import { desktopBackendClient } from './transport/desktop';

  setBackendClient(desktopBackendClient);
  mountApp();
  ```
- React mounts with the native IPC transport already active; zero HTTP session initialization or CSRF token handling executes.

### D. Desktop Transport Adapter (`web/src/transport/desktop.ts`)
- Implements `BackendClient` interface.
- Calls typed generated bindings in `web/src/bindings/downloader/cmd/desktop/desktopservice`.
- Dispatches StateSync events via `DesktopEventSubscription` using `@wailsio/runtime` `Events.On('godownloader.event', ...)`.
### E. Wails Task Pipeline (`Taskfile.yml`, `build/Taskfile.yml`, `build/windows/Taskfile.yml`)
- Root `Taskfile.yml` coordinates the unified build via `wails3 task build`.
- Pipeline dependencies:
  1. `common:install:frontend:deps`: npm dependency install.
  2. `common:go:mod:tidy`: Go dependency reconciliation.
  3. `common:generate:bindings`: generates TypeScript bindings directly into `web/src/bindings/`.
  4. `common:build:frontend`: runs `npm run build` (`tsc -b && vite build`) creating production assets in `web/dist/`.
  5. `windows:generate:syso`: generates `cmd/desktop/wails_windows_amd64.syso` embedding app icon, DPI-v2 manifest, and version metadata.
  6. `windows:build:native`: compiles production binary `bin/GoDownloader.exe` with `-tags production` and cleans up temporary `.syso` files.

### F. Clean-Checkout Asset Reproducibility (`web/embed_dev.go` / `web/embed_production.go`)
- In production (`-tags production`), `web/embed_production.go` embeds `all:dist`.
- In non-production builds (standard `go test ./...`, clean checkouts without pre-built `web/dist`), `web/embed_dev.go` (`//go:build !production`) exports an empty `embed.FS`.
- Verified: `go test -count=1 ./cmd/desktop/... ./web/...` succeeds immediately on a clean tree with no `web/dist` present.

### G. StateSync Gap Detection & Race Safety
- `DesktopEventSubscription` checks `options.getCursor?.()`: when `currentCursor > 0` and incoming event sequence satisfies `seq > currentCursor + 1`, an event gap is recognized and triggers `onSyncRequired({ cursor, reason: 'event_gap' })`.
- Frontend safely rehydrates from authoritative snapshot without dropped updates.
